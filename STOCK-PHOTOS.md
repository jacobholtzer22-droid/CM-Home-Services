# Stock Photos

Every image on this site is a free-license stock photo standing in until the owner sends real job photos. Swap each one when the owner's photos arrive: drop the new file in `public/images/originals/`, run `npm run images`, write its alt in `public/images/manifest.json`, point the config field at it, and delete the stock file and this row.

All files were downscaled to 2400px wide or less (never upscaled), re-encoded as JPG with all metadata (EXIF, GPS, IPTC, XMP, ICC) stripped, with no filters applied.
